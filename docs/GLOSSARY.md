# Glossary (Spanish → English)

Fixed terms for translating the documentation. They match the English texts of the site
(`web/textos/en.json`). Spanish originals are in [docs/es/](es/).

| Español | English |
|---|---|
| foco de calor, foco | hot spot |
| cuadrito de 1 km, cuadrito-día | 1 km grid cell, grid cell-day |
| lo normal (mediana 2001–2025) | normal (the 2001–2025 median) |
| serie armonizada | harmonized series |
| armonizar | harmonize |
| factor (de un satélite) | factor (of a satellite) |
| salto de 2012 | the 2012 jump |
| días sin datos (del satélite) | days without satellite data |
| satélite de respaldo | backup satellite |
| temporada de quemas | burning season |
| quema, quema agrícola | burn, agricultural burn |
| permiso de quema | burning permit |
| fechas permitidas / ventana oficial | allowed dates / official window |
| zona de quema (zona 1, 2, 3…) | burning zone |
| guardarraya | firebreak (*guardarraya*) |
| municipio / presidente municipal | municipality / mayor |
| incendio | wildfire |
| día solar local | local solar day |
| tarea N | task N |
| el jurado | the jury |
| pitch / guion | pitch / script |

Proper names stay as they are: K'áak', CONAFOR, SEDER, CONABIO, FIRMS, MODIS, VIIRS,
S-NPP, NOAA-20, NOAA-21, Aqua, Terra.

Numbers, tables, quotations and sources are copied exactly. Decimal separators follow English
(`8,757`, `0.95`).
