# Peninsula data (ready to use)

The team's working package. It is generated by `analisis/preparar_peninsula.py` from the raw data
(which is not in Git because of its size, ~900 MB). Data through 2026-11-07 (YYYY-MM-DD).

Spanish original: [es/LEEME.md](es/LEEME.md).

## Files

| File | What it is | Size |
|---|---|---|
| `focos_peninsula.parquet` | All FIRMS fire hot spots in Yucatán, Campeche and Quintana Roo, from all satellites, with state and municipality | 24 MB |
| `incendios_conafor_2015_2024.csv` | Wildfires recorded by CONAFOR in the three states (one per row: date, municipality, hectares, cause) | 0.4 MB |
| `estados_peninsula.geojson` | Boundaries of the three states (simplified) | — |
| `municipios_peninsula.geojson` | Municipal boundaries (simplified) | 1 MB |

**Burning zone of each municipality:** `analisis/municipios_zona.csv` (municipality, state, zone and
official burning window). It is the table to use to join hot spots with zones: it already fixes the
names that are spelled differently (Dzán, Tixmehuac).

## Hot spots: main columns

| Column | Meaning |
|---|---|
| `acq_date`, `acq_time` | UTC date and time of the satellite pass (`acq_time` in HHMM format) |
| `latitude`, `longitude` | Center of the pixel where fire was detected |
| `sensor` | `MODIS` (Terra and Aqua), `S-NPP`, `NOAA-20` or `NOAA-21` |
| `satellite` | `Terra` / `Aqua` for MODIS; `N` (S-NPP), `N20`, `N21` for VIIRS |
| `producto` | `SP` (standard processing, final) or `NRT` (near real time, the most recent) |
| `confidence` | MODIS: 0–100. VIIRS: `l` low, `n` nominal, `h` high |
| `type` | 0 = presumed vegetation fire, 2 = other fixed source on land, 3 = at sea. Empty in NRT |
| `frp` | Fire radiative power (MW): how intense it is |
| `daynight` | `D` day, `N` night |
| `municipio` | Municipality where the hot spot falls (geoBoundaries limits) |
| `estado` | The state of its municipality. Only hot spots that fall in no municipality (0.2 %) take the state from the states map |

**Filter we use for the figures in docs/01:** `type == 0` (or empty in NRT) and nominal or high
confidence (VIIRS `n`/`h`, MODIS ≥ 30).

## Coverage by satellite

| Satellite | From | To |
|---|---|---|
| MODIS (Terra) | Nov 6, 2000 | Nov 6, 2026 |
| MODIS (Aqua) | Jul 4, 2002 | Nov 5, 2026 |
| S-NPP | Jan 20, 2012 | Nov 2, 2026 (stopped sending data that day) |
| NOAA-20 | Apr 1, 2018 | Nov 7, 2026 |
| NOAA-21 | Mar 1, 2023 | Nov 7, 2026 |

## How to load it (Python)

```python
import pandas as pd
focos = pd.read_parquet("datos_peninsula/focos_peninsula.parquet")
yuc = focos[(focos.estado == "Yucatán") & (focos["type"].fillna(0) == 0)]
viirs = yuc[yuc.sensor.isin(["S-NPP", "NOAA-20", "NOAA-21"]) & yuc.confidence.isin(["n", "h"])]
print(viirs.groupby(viirs.acq_date.dt.year).size())
```

You need `pandas` and `pyarrow` (`pip install pandas pyarrow`).

## Cautions

- **A hot spot is not a wildfire.** A large wildfire produces many hot spots.
- **Don't add VIIRS satellites without removing duplicates**: they see the same fire minutes
  apart.
- The boundaries are approximate (geoBoundaries uses an old municipal map). Three recently created
  municipalities are missing: Puerto Morelos (Quintana Roo), and Seybaplaya and Dzitbalché
  (Campeche). Their hot spots stay in the municipality they split from.
- Tzucacab (Yucatán) was assigned to Quintana Roo by an error in the states map; it was fixed in
  `analisis/preparar_peninsula.py`.
